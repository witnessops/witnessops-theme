# Icon-set tools

- `inventory_icons.py` reads launcher icon metadata into a private inventory.
- `launcher_icon_overrides.py` plans, applies, verifies and restores narrowly scoped user launcher icon overrides.
- `preview_icon_set.py` renders the actual package artwork at desktop sizes.

The root build, install and packaging scripts are documented in [ICONSET.md](../ICONSET.md). Keep host inventories, receipts, backups and previews in ignored local paths.
